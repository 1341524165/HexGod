# 装备购买顺序与商店可用性核对（16.15）

范围：本地英雄装备统计或下一件候选池出现的全部 **126 个装备 ID**。
下一件候选池有 **90 个 ID**；其中 **82 个可直接购买**，另有 **4 个不能直接购买**、**4 个嚎哭深渊不可用**。
其余 **36 个**仅出现在统计数据中，不进入当前下一件候选池。

处理：**7 个旧 ID 改指向可买的基础装备或地图版本**；去重后剩余 **85 个有效购买候选**。歌之权冠没有确认可买路线，已从直接购买建议中排除。

来源：[Riot 16.15.1 中文装备资料](https://ddragon.leagueoflegends.com/cdn/16.15.1/data/zh_CN/item.json)（本地快照：`sources\riot_item_16.15.1_zh_CN.json`）；[Riot 地图表](https://static.developer.riotgames.com/docs/lol/maps.json) 将 12 标为嚎哭深渊。

狂徒铠甲是当前可买候选中确认需要已有大量额外生命值的项目。程序不把它列为首件成装；
之后根据已同步物品的基础生命值和狂徒自身的 12% 装备生命值增幅保守估算，未到 2000 额外生命值时仍不列入主推荐。
该估算不包含海克斯增益或心之钢等后续叠层，因此可能延后显示，不会据此声称实战属性的精确值。
大天使之杖、魔宗、凛冬之临可以购买并自行叠层；它们的进化形态不能直接购买。
无尽之刃、灭世者的死亡之帽、界弓、千变者贾修、裂隙制造者和黎明核心等首件时核心效果也能触发，
故只考虑统计排序与英雄适配，不设一刀切首件禁令。
